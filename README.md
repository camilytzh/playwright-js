# Practice Software Testing
## Tools
- Playwright
- Javascript
## Prerequisites
- Node.js (Preferably v18+)
- npm
- git
## Steps to reproduce tests
### 1. Clone the repository
`git clone https://github.com/camilytzh/playwright-js.git`
### 2. Install dependencies
`npm install`
### 3. Install Playwright browsers
`npx playwright install`
### 4. Execute tests
`npx playwright test`
### 5. Generate report
`npx playwright test --reporter=html`
